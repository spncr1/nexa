# Changelog

This changelog follows Semantic Versioning. The root `VERSION` file is the authoritative source for the current product version.

## Current baseline

### 2.1.1 - Established 2026-10-15

Nexa is a coherent academic-planning MVP with a dashboard, task and assignment planning, study-session planning, account workflows, persistent PostgreSQL-backed data, email reminders, system settings, and a responsive welcome experience.

This is the first formally established project version in this repository. The project had no earlier version tags or changelog, so the history below records evidence-backed development milestones rather than claiming that formal releases occurred on those dates.

## Historical milestones (not formal releases)

### September 2026 - Responsive refinements

- Improved the welcome page on mobile devices.
- Fixed assignment-page overscroll behaviour.

### August 2026 - Welcome and account-flow improvements

- Added the public Nexa welcome page and connected it to login and account creation.
- Corrected email confirmation behaviour.
- Fixed profile saving, avatar upload, and profile-settings layout.

### June-July 2026 - Second-generation product redesign

- Refocused Nexa as a dedicated academic-planning application.
- Added the full Study Planner workflow.
- Reworked the backend around structured PostgreSQL-backed product data and migrations.
- Centralised interface styling, shared controls, settings, navigation, and theme handling.
- Completed substantial responsive, workflow, and visual redesigns across the application.

### April-May 2026 - Accounts and persistent data

- Added authentication, PostgreSQL persistence, and server-side sessions.
- Added account validation, password reset, and account-management workflows.
- Restructured the application for server rendering and deployment.

### March 2026 - First coherent application milestone

- Completed integrated dashboard, task, assignment, and calendar workflows.
- Added dark mode and deployment preparation.
- Documented the first usable browser-based product.
